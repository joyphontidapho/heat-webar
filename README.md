# WebAR: ความร้อนกับการเปลี่ยนแปลงของสาร

เว็บแอป AR แบบ static (ไม่มี backend) สำหรับนักเรียน ม.1 ใช้คู่กับชุดกิจกรรม AR-Integrated Inquiry Kit
นักเรียนสแกน QR บนการ์ด → เปิดกล้อง → ส่องการ์ด → เห็นแบบจำลองอนุภาค 3 มิติบนการ์ด
ทุกฉากมี **โหมด 3D (ไม่ใช้กล้อง)** สำรองไว้เมื่อกล้องเปิดไม่ได้หรือเครื่องช้า

> สถานะ: **ระยะที่ 1 (ต้นแบบ)** มี 2 ฉากคือ AR-1A และ AR-3A ส่วนอีก 8 ฉากจะทำในระยะที่ 2
> ดูรายละเอียดใน [PROJECT_STATUS.md](PROJECT_STATUS.md)

## เทคโนโลยี (ล็อกเวอร์ชัน)

| ส่วน | ที่ใช้ | ที่อยู่ในโปรเจกต์ |
| --- | --- | --- |
| AR tracking | MindAR **1.2.5** (Image Tracking, MIT) | `vendor/mindar-1.2.5/` |
| 3D rendering | A-Frame **1.5.0** (MIT) | `vendor/aframe-1.5.0/` |
| ฟอนต์ | Sarabun (SIL OFL 1.1) | `vendor/fonts/` |
| QR (เฉพาะเครื่องมือสร้างการ์ด) | qrcode-generator 2.0.4 (MIT) | `tools/lib/qrcode.js` |

MindAR 1.2.5 คู่กับ A-Frame 1.5.0 ตามที่เอกสาร MindAR ระบุ (หน้า Quick Start ของ MindAR ใช้ `aframe 1.5.0` กับ `libVersion 1.2.5`)
ไลบรารีทั้งหมดเก็บสำเนาไว้ใน repo ไม่โหลดจาก CDN แอปจึงไม่พังเมื่อ CDN เปลี่ยน และไม่ส่งข้อมูลออกไปที่ใด

## โครงสร้าง

```
heat-webar/
├── index.html              หน้าเมนู (สร้างรายการจาก config.js)
├── config.js               ข้อความ ค่าคงที่ อุณหภูมิ ทุกฉาก ← ครูแก้ไฟล์นี้ไฟล์เดียว
├── css/app.css             หน้าตาแอป + ฟอนต์
├── scenes/
│   ├── ar-1a.html, ar-3a.html   หน้าฉาก AR (ไฟล์สั้น โหลดโค้ดจาก js/)
│   └── viewer.html?scene=ar-1a  โหมด 3D ไม่ใช้กล้อง (หน้าเดียว รับพารามิเตอร์)
├── js/
│   ├── particles.js        ระบบอนุภาคใช้ร่วมกัน (ของแข็ง/ของเหลว/แก๊ส)
│   ├── ui.js               ปุ่ม ป้าย การขอสิทธิ์กล้อง การแจ้งเตือน
│   └── scenes/ar-1a.js …   เนื้อหาของแต่ละฉาก (ใช้ร่วมกันทั้งโหมด AR และ 3D)
├── targets/
│   ├── cards/*.png         ภาพการ์ด 300 dpi (A5 แนวนอน)
│   ├── src/*.svg           ไฟล์ต้นฉบับการ์ด (แก้ต่อใน Inkscape/Illustrator/Figma ได้)
│   └── *.mind              ไฟล์เป้าหมายที่คอมไพล์แล้ว (1 ไฟล์ต่อ 1 ฉาก)
├── print/
│   ├── cards-A5.pdf        การ์ดพร้อมพิมพ์ (รหัสฉาก QR คำถามนำ)
│   └── qr-codes.pdf        QR ของเมนูรวมและทุกฉาก
├── tools/cards/            เครื่องมือสร้างการ์ด/คอมไพล์ .mind/สร้าง PDF
├── tests/e2e.cjs           ชุดทดสอบอัตโนมัติ (Playwright)
├── docs/teacher-guide.md   คู่มือครู
└── vendor/                 สำเนาไลบรารีที่ล็อกเวอร์ชัน
```

ต่างจากโครงสร้างใน Dev Brief เล็กน้อย 2 จุด: เพิ่ม `js/scenes/` เพื่อให้โหมด AR และโหมด 3D ใช้โค้ดฉากชุดเดียวกัน (แก้ที่เดียวเปลี่ยนทั้งสองโหมด) และเพิ่ม `targets/src/` สำหรับไฟล์ต้นฉบับการ์ด

## Deploy บน GitHub Pages (ทำครั้งเดียว)

1. ที่ repo บน GitHub ไปที่ **Settings → Pages**
2. **Source:** Deploy from a branch → **Branch:** `main` / **Folder:** `/ (root)` → Save
3. รอ 1–2 นาที แล้วเปิด `https://joyphontidapho.github.io/heat-webar/`
4. ตรวจหลัง deploy: เปิดหน้าเมนูบนมือถือ → กด "ดูแบบ 3D" ทุกฉาก → กด "เปิดกล้อง AR" แล้วส่องการ์ดที่พิมพ์

ไม่มี build step ไม่มีค่าใช้จ่าย GitHub Pages ให้ HTTPS อัตโนมัติ (จำเป็นต่อการเปิดกล้อง)
ข้อจำกัด: repo ต้องเป็น public (สำหรับบัญชีฟรี) และ GitHub Pages มีโควตาแบนด์วิดท์ 100 GB/เดือน ซึ่งเกินพอสำหรับห้องเรียน

ถ้าเปลี่ยนที่อยู่เว็บ (เช่น ย้าย repo) ให้แก้ `siteUrl` ใน `config.js` แล้วสร้างการ์ดและ QR ใหม่ (ดูด้านล่าง) เพราะ QR ชี้ไปที่อยู่เดิม

## ครูแก้ข้อความและตัวเลข

แก้ใน `config.js` อย่างเดียว ไม่ต้องแตะโค้ดฉาก (แก้บนเว็บ GitHub ได้: เปิดไฟล์ → ปุ่มดินสอ → Commit changes)

- ข้อความบนปุ่ม/ป้าย: `text: { … }`
- อุณหภูมิบีกเกอร์ AR-1A: `scenes["ar-1a"].beakers[].tempC`
- ค่าคงที่ c, L: `constants: { … }`
- ความกว้างแต่ละช่วงของกราฟ AR-3A: `scenes["ar-3a"].segments[].width`
- ความเร็วที่ขยายให้เห็นชัด: `particles.speedExaggeration` (1 = ตามจริง ∝ √T)
- คำถามนำบนการ์ด: `scenes[…].cardQuestion` (ต้องสร้างการ์ดใหม่จึงจะเปลี่ยนบนกระดาษ)

ตรวจไฟล์หลังแก้: เปิดหน้าเว็บแล้วถ้าหน้าเมนูว่าง แปลว่าเครื่องหมาย `,` `"` หรือ `}` หายไป ให้ย้อนการแก้ไขบน GitHub (History → Revert) ได้

## สร้างการ์ด / คอมไพล์ .mind / PDF ใหม่ (สำหรับผู้พัฒนา)

ต้องมี Node.js 18+ และ Playwright

```bash
npm i -D playwright && npx playwright install chromium
node tools/cards/build-cards.cjs          # ทุกฉากที่ ready: true
node tools/cards/build-cards.cjs ar-1a    # เฉพาะฉากเดียว
```

สคริปต์จะวาดการ์ดจาก `tools/cards/card-template.js` + ข้อความใน `config.js` แล้วคอมไพล์ `.mind` ด้วยตัวคอมไพเลอร์ของ MindAR 1.2.5 (`tools/mindar-compiler/`)
ถ้าแก้การ์ดเองในโปรแกรมวาดภาพ ให้คอมไพล์ภาพใหม่ที่ [MindAR Image Targets Compiler](https://hiukim.github.io/mind-ar-js-doc/tools/compile) แล้ววางไฟล์ทับที่ `targets/<ฉาก>.mind`

**สำคัญ:** การ์ดที่พิมพ์ต้องเป็นภาพเดียวกับที่ใช้คอมไพล์ `.mind` ถ้าแก้การ์ดแล้วไม่คอมไพล์ใหม่ กล้องจะจับไม่ได้

## ทดสอบ

```bash
node tests/e2e.cjs     # ต้องมี ffmpeg ด้วย (สำหรับข้อทดสอบกล้องจำลอง)
```

ทดสอบ: ขนาดอนุภาคคงที่, น้ำร้อนเร็วกว่าน้ำเย็น, อุณหภูมิค้างที่ 0/100 °C ขณะเปลี่ยนสถานะ, ค่าในฉากตรงกับ `config.js`,
ปฏิเสธสิทธิ์กล้องแล้วมีทางไปโหมด 3D, ไม่มีการเรียกไฟล์นอกเว็บไซต์, ฟอนต์ไทย, และจับการ์ดได้ผ่านกล้องจำลอง (Chromium ใช้ภาพการ์ดแทนกล้อง)

ชุดทดสอบนี้ **ไม่ได้** ทดสอบการจับการ์ดผ่านกล้องมือถือจริง แสงในห้องเรียน หรือ fps บนมือถือจริง ส่วนนี้ต้องทดสอบด้วยมือตาม Dev Brief ข้อ 11

## ความเป็นส่วนตัว

- ไม่มี analytics ไม่มีคุกกี้ ไม่เก็บข้อมูลใด ๆ
- ภาพจากกล้องประมวลผลในเครื่องเท่านั้น ไม่บันทึก ไม่ส่งออก
- ฟอนต์และไลบรารีทั้งหมดโหลดจากเว็บไซต์ของแอปเอง (ไม่ใช้ Google Fonts หรือ CDN)
- ทุกหน้ามี `<meta name="referrer" content="no-referrer">`
