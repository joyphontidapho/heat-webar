# คู่มือครู (ฉบับสั้น) · WebAR ความร้อนกับการเปลี่ยนแปลงของสาร

> ฉบับร่างระยะที่ 1 (ต้นแบบ 2 ฉาก: AR-1A และ AR-3A)

## เตรียมก่อนสอน

1. พิมพ์ `print/cards-A5.pdf` บนกระดาษ A5 (หรือ A4 ย่อพอดีหน้า) แบบสี **ไม่ต้องเว้นขอบ**
2. ใส่การ์ดในซองพลาสติกใส หรือเคลือบแบบด้าน (การเคลือบเงาสะท้อนแสงไฟ ทำให้กล้องจับยากขึ้น)
3. พิมพ์ `print/qr-codes.pdf` ติดหน้าห้อง (QR "เมนูรวม" พาไปหน้ารวมทุกฉาก)
4. ทดลองเปิดเองก่อน 1 รอบบนมือถือของครู ด้วย Wi-Fi ของโรงเรียน

## นักเรียนใช้งานอย่างไร

1. สแกน QR บนการ์ดด้วยกล้องมือถือ
2. กด **เปิดกล้อง** แล้วกด **อนุญาต** เมื่อเบราว์เซอร์ถามสิทธิ์กล้อง
3. ส่องกล้องไปที่การ์ดให้เห็นทั้งใบ ห่างประมาณ 25–40 ซม. ฉากจะปรากฏบนการ์ด
4. ใช้ปุ่มด้านล่างจอ (ปุ่ม **หยุด/เล่น** ใช้หยุดภาพเพื่อสังเกตหรือจดบันทึก)
5. ถ้ากล้องเปิดไม่ได้ กด **ดูแบบ 3D (ไม่ใช้กล้อง)** แล้วใช้นิ้วลากเพื่อหมุนดู

## สิ่งที่แต่ละฉากแสดง

| ฉาก | สิ่งที่นักเรียนเห็น | การโต้ตอบ |
| --- | --- | --- |
| AR-1A | บีกเกอร์ A (10 °C) และ B (60 °C) อนุภาคในบีกเกอร์ B เคลื่อนที่เร็วกว่า | แตะบีกเกอร์เพื่อเปิดป้ายอุณหภูมิ (เริ่มต้นซ่อนไว้ ให้นักเรียนสังเกตก่อน) |
| AR-3A | กราฟอุณหภูมิกับเวลา −10 → 110 °C และกล่องอนุภาคที่เปลี่ยนตามช่วง | แตะช่วงบนกราฟหรือกดปุ่ม 1–5 จุดแดงจะวิ่งผ่านช่วงนั้นซ้ำไปเรื่อย ๆ |

## ข้อควรรู้เรื่องความถูกต้องของภาพ (บอกนักเรียนได้)

- **ความเร็วอนุภาคถูกขยายความต่างให้เห็นชัด** ในความจริงน้ำ 60 °C มีอนุภาคเร็วกว่าน้ำ 10 °C ประมาณ 8% เท่านั้น ภาพนี้ขยายให้ต่างราว 2 เท่า แต่ทิศทางถูกต้องเสมอ (ร้อนกว่า = เร็วกว่า)
- **อนุภาคไม่ขยายขนาดเมื่อร้อน** ที่เห็นคือระยะห่างเพิ่มขึ้นเล็กน้อย
- **กราฟ AR-3A ไม่ตามสเกล** ถ้าวาดตามจริง ช่วงเดือด (2,256 J/g) จะยาวกว่าช่วงหลอมเหลว (334 J/g) เกือบ 7 เท่า ตัวกราฟจึงย่อให้เห็นครบ 5 ช่วง
- ขณะหลอมเหลวและขณะเดือด ป้ายอุณหภูมิค้างที่ 0 °C และ 100 °C และอนุภาคสั่น/เคลื่อนที่เร็วเท่าเดิม สิ่งที่เปลี่ยนคือการจัดเรียง

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
| --- | --- |
| เปิดจาก LINE แล้วกล้องไม่ทำงาน | QR บนการ์ดตั้งให้ LINE เปิดในเบราว์เซอร์อัตโนมัติ ถ้ายังไม่ได้ ให้กดปุ่ม ⋯ มุมขวาบน → เปิดในเบราว์เซอร์ |
| ขึ้น "เปิดกล้องไม่ได้" | เคยกด "ไม่อนุญาต" ไว้: เข้าการตั้งค่าเบราว์เซอร์ → สิทธิ์เว็บไซต์ → กล้อง → อนุญาต หรือใช้โหมด 3D แทน |
| ส่องแล้วไม่ขึ้น | ให้เห็นการ์ดทั้งใบ แสงพอ ไม่มีเงามือบัง ไม่มีแสงสะท้อนบนซองพลาสติก ถือนิ่ง 1–2 วินาที |
| ภาพสั่นหรือกระตุก | วางการ์ดบนโต๊ะแล้วถือมือถือนิ่ง ๆ หรือปิดแอปอื่นในเครื่อง |
| เครื่องช้ามาก | ใช้โหมด 3D (ไม่ใช้กล้อง) ซึ่งใช้ทรัพยากรน้อยกว่า |

## แก้ข้อความหรือตัวเลขในฉาก

แก้ในไฟล์ `config.js` ไฟล์เดียว (แก้บนเว็บ GitHub ได้) รายละเอียดอยู่ใน README หัวข้อ "ครูแก้ข้อความและตัวเลข"
ค่าคงที่ทางวิทยาศาสตร์ทุกค่าควรตรวจกับหนังสือเรียนก่อนใช้จริง (โดยเฉพาะ c ของไอน้ำ ที่ตั้งไว้ 2.0 J/g·°C)

## ความเป็นส่วนตัวของนักเรียน

แอปไม่เก็บชื่อ ไม่เก็บภาพ ไม่มีระบบติดตาม ภาพจากกล้องประมวลผลในเครื่องเท่านั้น
